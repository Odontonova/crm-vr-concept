# Padrão de Comportamento:
Quando for alterar algo, pense passo a passo, detalhe por detalhe, para que não haja nenhum tipo de erro. 

Não gere nenhum erro com as alterações que forem solicitadas, principalmente o erro de gerar tela branca. Tome muito cuidado com isso. 

Não altere absolutamente nada do sistema que não tenha solicitado. Altere somente aquilo que foi solicitado.

Somente altere o design caso seja solicitado. Se não for solicitado, mantenha o design, layout, cores, padrões, exatamente do jeito que estão.
